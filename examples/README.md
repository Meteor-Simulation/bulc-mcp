# Examples — synthetic data only / 예제 — 모두 합성 데이터

모든 예제는 이 저장소의 스크립트로 만든 **가상 데이터**입니다. 실제 건물, 프로젝트, 고객의 도면·결과와 관계가 없습니다.
Every example here is **invented data** produced for documentation and tests. None of it comes from a real building,
project or customer.

| Path | What it is |
|---|---|
| `drawings/office-plan-synthetic.dxf` | 20 m × 12 m office floor plan, units mm: 200 mm outer walls (double lines), a 100 mm partition, two door blocks, window lines. Generated by `scripts/gen-example-drawings.mjs`. |
| `drawings/water-spray-iso-synthetic.dxf` | Water-spray piping isometric: inlet, riser, main and two zones of three open nozzles with zone valves and line-number labels. No DIMENSION entities — pass `options.scaleMmPerUnit: 1` to `spr_analyze_drawing`. Generated by the same script. |
| `decks/room_fire_synthetic.fds` | A single room with a 500 kW propane burner, heat detector, slices and Plot3D. `bulc_check_deck` reports no findings. |
| `decks/broken_deck_synthetic.fds` | A deck with deliberate mistakes; each line names the rule it breaks. Used by the tests. |
| `sessions/*.md` | Example conversations showing the order of tool calls (responses shortened). |

Regenerate the drawings with `npm run gen:examples`. Do not add real drawings or project files here — see
`PRIVACY_POLICY.md` and rule GEN-012.
